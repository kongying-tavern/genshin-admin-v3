# 地图设置中的 system.json 配置查看器开发计划

基线为 `dev@b0b5a59e`。目前「系统设置 → 地图 → 状态」展示配置签名和版本，「查看配置」只把合并后的地区底图打印到控制台。将这个按钮接到设置弹窗内的只读详情页，让维护者可以回答三个问题：某个地区使用哪张底图、切换地区时视口落在哪里、这些值取自哪段配置。[地图设置入口](../../src/components/AppSettings/modules/ModuleMapSetting.vue) · [设置弹窗](../../src/components/AppSettings/AppSettings.vue)

本计划约定用户操作、数据含义和验收结果。执行者 Sol 自主决定布局、配色、图形、字体和动效。先前的交互原型仅用于说明字段关系，正式界面应能浏览当前配置中的全部可见条目。

## 一、从地图设置进入和返回

- 打开时默认选中主地图当前地区。如果该地区没有可见配置，选取第一个可见且有底图配置的地区。地区列表来自当前角色可见的地区数据，以地区代码关联配置；多个地区即使共用同一个底图代码，也可以分别查看。继承模板从引用它的地区进入。[地区列表](../../src/stores/area.ts) · [底图索引](../../src/stores/tile.ts)
- 查看器中的选区、切换叠层项、查看原文均为临时浏览操作。返回后仍在原地图设置页，焦点回到「查看配置」，主地图的地区、视口、叠层选择和账号偏好均保持进入前的值。
- 复用页面已经加载的配置。加载中、暂无可见地区、某地区未启用叠层分别给出对应状态。地区数据未就绪时仍可浏览已有的全局资源。恢复订阅或从开发者页加载本地测试配置后，查看器显示同一份新配置及其摘要。[配置加载](../../src/stores/dadian.ts) · [开发者入口](../../src/components/AppSettings/modules/ModuleDeveloper.vue)

## 二、查看器应能回答的问题

| 视图 | 用户可以核对什么 |
| --- | --- |
| 地区底图与坐标 | 展示地区代码、底图名称和代码、尺寸、格式、瓦片偏移、点位原点、初始视口中心和缩放。等比示意图标出底图边界、点位原点、初始视口中心；文字同时给出坐标和字段来源。 |
| 叠层与插件 | 按地区展开全部叠层分组、图层项和可选分片。点选后显示角色（普通叠层或底图叠层）、选择方式、原始点位边界和换算后的地图边界。另列该地区启用的点位扩展及配置，例如地下层级或海岛阶段。 |
| 配置原文 | 由当前地区定位到地区底图、引用模板、地区插件的 JSON 路径和只读片段。具备 Beta 权限时，可核对参与计算的正式与 Beta 片段。模板继承、代码默认和内置覆盖产生的值应出现在生效值中，原文片段保留输入时的字段。 |
| 全局资源 | 按 `application` 查看头像、名片，按 `editor` 查看字体、快捷输入、特殊刷新时间、公告文本。列表显示实际数量，条目可查看字段和值。资源类别缺失、数组为空或资源图片加载失败时，仍可读取其他配置和条目原文。 |

### 坐标的计算口径

1. `tiles[地区].center` 是点位坐标 `(0, 0)` 在地图中的位置。底图的像素范围由 `tilesOffset` 和 `size` 决定，从 `(ox, oy)` 到 `(ox + width, oy + height)`。[瓦片范围](../../src/packages/map/src/core/gsTileLayer.ts)
2. `settings.center` 是点位坐标。进入地区时，取内置地区 `target`、配置的视口中心、默认值 `[0, 0]` 中首个有效值，再加上点位原点，得到地图坐标。缩放取生效的 `settings.zoom`。例如希穆兰卡样例的点位原点为 `[3568, 6286]`，视口中心为 `[500, -2211]`，地图落点应为 `[4068, 4075]`。[主地图切区逻辑](../../src/HomePage.vue) · [内置地区配置](../../src/configs/areas.ts)
3. 叠层范围沿用现有分片、图层项、分组的边界回退规则。两个端点分别加上该地区点位原点即可得到地图边界。对缺失有效边界的条目标明原因；图幅尺寸缺失或为零时，保留可读字段并给出示意图空态。[叠层归一化](../../src/stores/overlay.ts)

## 三、实施顺序

1. **让原文与生效值能够独立核对。** 订阅解压成功和本地文件校验成功都是配置入口。当前底图、叠层和点位扩展在派生计算中使用会修改输入的 `merge` 或 `defaultsDeep`。在第一次合并前保留该次输入，或让所有相关合并写入独立对象。沿用现有摘要和版本的计算方式，把地区、模板、插件的原文取自同一次加载。[配置类型](../../src/api/config/typings.d.ts) · [订阅配置 store](../../src/stores/dadian.ts)
2. **复用运行时解析，并记录来源。** 底图按现有规则组合正式配置、角色可用的 Beta 配置和一层 `extend`，再使用默认值及内置地区视口覆盖。按字段记录来源路径，例如 `tiles["提瓦特-base1"].center`。用同一份解析结果驱动列表、坐标图和生效值；叠层和点位扩展分别复用各自的选择与合并语义。[底图](../../src/stores/tile.ts) · [叠层](../../src/stores/overlay.ts) · [点位扩展](../../src/stores/markerExtra.ts)
3. **在设置弹窗内接入只读浏览。** 先打通「查看配置 → 当前地区 → 生效值 → 配置原文 → 返回」，再接入叠层、插件和全局资源。使用局部状态保存浏览选择。沿用 `accessStore.hasBeta` 和地区可见性规则筛选列表、计数、版本、来源及原文。角色变化时立即重算，若当前片段失去访问权限，同时清除选中项和展开详情。[权限判断](../../src/stores/access.ts)

## 四、验收与回归

以下地区是可复现的业务示例。自动化测试使用最小本地样例，预期值独立于线上订阅版本。

| 场景 | 通过条件 |
| --- | --- |
| 希穆兰卡 | 视口与点位原点可区分，地图落点符合上述算例。选择「星轨王城 → 城堡中部」能看到该分片的两套边界。底图原文只包含地区提供的字段，继承值可追到模板。 |
| 金苹果群岛 1.6、蒙德 | 前者可逐项查看两个阶段的整图叠层及继承的分组边界；后者显示无叠层，仍可查看室内标记插件。浏览两者期间主地图的筛选、视口、叠层状态保持一致。 |
| 来源与权限切换 | 构造有 Beta 覆盖、模板继承、默认值和内置视口覆盖的样例。反复浏览后输入与初始样例深度相等。调低权限时，Beta 独有地区、版本值和已展开原文同时消失，普通地区恢复正式配置。 |
| 配置切换、资源和空态 | 加载另一份测试配置或恢复订阅后，元信息、地区详情及原文一起更新。无当前地区、无尺寸、无公告或资源列表为空时均可继续导航。全局资源按该配置的真实数量展示。 |
| 真实入口与窄屏 | 从地图设置按钮进入并返回。键盘可完成选区、查看图层和查看原文；窄屏可读到完整字段路径和数值；使用文字可区分两个坐标标记及字段来源。 |

在现有配置 store 单测旁补充输入不变性、权限切换和坐标换算用例，并以组件测试覆盖入口、选区和返回。实现完成后运行 `pnpm typecheck`、`pnpm test:run --project unit`、`pnpm lint`、`pnpm build`，对实际改动的源码做 oxfmt 检查，再从设置弹窗执行上述浏览验收。[现有配置单测](../../tests/stores/systemConfig.test.ts)
